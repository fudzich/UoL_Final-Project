Выпускной проект в University of London. Игра в жанре Roguelike с элементами Bullet hell. Разработка велась около 1 месяца.

Достижения:
  - Адаптировал алгоритм поиска путей для процедуральной генерации окружения
  - Организовал работу с большим количеством процедурально генерируемой информации. Её отслеживанием и сохранением в памяти между сценами.
  - Оптимизировал вычисления для полноценной работы в браузере
  - Использовал элементы диетического интерфейса для большего вовлечения игроков
  - Использовал собственные 3Д модели и другие ассеты
